# Пивбар — лендинг крафт-бара

Одностраничный лендинг в тёмной редакционной стилистике: крупная сжатая
типографика, кремовый текст, янтарный акцент, плавные появления блоков,
параллакс и hover-анимации. Статический сайт — без сборки, фреймворков
и серверной части.

## Быстрый старт

Откройте `index.html` в браузере — сайт готов к работе. Шрифты подгружаются
с Google Fonts (нужен интернет); без них срабатывают системные запасные шрифты.

Чтобы проверить именно **встроенную** форму (iframe), запустите локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

и откройте `http://localhost:3000` (или `http://localhost:8000`).

> При открытии файла двойным щелчком (`file://`) Яндекс Формы запрещают
> встраивание в iframe, поэтому кнопки открывают форму **отдельным окном**
> по центру поверх страницы. На хостинге форма встроена в модальное окно.

## Структура проекта

| Файл | Назначение |

| `index.html` | Разметка, тексты, SVG-иконки, модальное окно формы и `<template>` с кодом встраивания |

Секции страницы: первый экран, бегущая строка, «На кранах и на сцене»,
«Знакомая ситуация…», «Решение», CTA-полоса, дегустационный сет, финальный CTA,
подвал.

## Как обновлять меню с телефона

Все краны и анонс сцены находятся в `assets/js/content.js`:

1. Откройте файл в GitHub (или в любом мобильном редакторе).
2. Измените `name`, `style`, `abv`, `color` у нужного крана.
3. Обновите `updated` — дата появится под заголовком «На кранах и на сцене прямо сейчас».
4. Сохраните (Commit changes). После деплоя блок обновится сам.

Поля крана: `name` — название, `style` — стиль, `abv` — крепость,
`color` — цвет маркера в формате `#hex`. Блок `stage` задаёт день, время,
заголовок, текст и теги анонса сцены.

Названия сортов в файле — **демонстрационные**. Замените их на реальное меню.

## Бронирование и Яндекс Форма

Все кнопки с атрибутом `data-cta` открывают форму бронирования. Кнопок шесть:
в шапке, на первом экране, после блока «Решение», в билете оффера,
на финальном экране и в подвале.

- Код встраивания целиком (вместе со строкой `<script>`) лежит в `index.html`
  внутри `<template id="yaFormTemplate">`. Он вставляется в окно только при
  первом нажатии, чтобы не замедлять загрузку страницы.
- Форма растягивается на всю ширину окна, в том числе на телефоне.
- Закрытие — кнопкой ✕ или клавишей `Esc`; прокрутка страницы на время окна блокируется.
- В шапке окна есть ссылка «Открыть в новой вкладке» на случай блокировки iframe.
- При работе с `file://` форма открывается отдельным popup-окном 820×760 px
  по центру экрана.
- Google Таблицы и скрипт Code.js **не используются** — заявки приходят сразу
  в вашу Яндекс Форму.

## Что уже есть

- Адаптив: 3 колонки на десктопе → 1 колонка на мобильных у карточек кранов, болей и решений.
- Появление блоков через `IntersectionObserver` с каскадной задержкой.
- Параллакс у бейджа, круга со стаканом и фонового слова в финале.
- Бегущая строка, вращающийся текст на янтарном круге и увеличение фото при наведении.
- Липкая шапка, которая прячется при скролле вниз и возвращается при скролле вверх.
- Мобильное меню с блокировкой скролла и закрытием по `Esc`.
- Поддержка `prefers-reduced-motion`: анимации отключаются, контент показывается сразу.
- Доступность с клавиатуры: `focus-visible`, skip-link, семантика секций.
  Lighthouse: Accessibility, Best Practices и SEO — 100.
