# AGENTS.md

Инструкции для ИИ-агентов и разработчиков, работающих с этим лендингом.

## Обзор проекта

Статичный одностраничный сайт крафт-бара на русском языке. Стиль — тёмная
редакционная типографика: кремовый текст, янтарный акцент, крупные заголовки,
появления блоков при скролле, параллакс и hover-анимации.

**Важно:** это не приложение и не сборка. Нет `package.json`, фреймворков,
сборщиков и транспайлеров. Любое изменение — правка обычных HTML/CSS/JS-файлов.

## Ограничения

- Не добавлять сборщики, npm-зависимости и фреймворки без явной просьбы.
- Не использовать Google Таблицы и скрипт Code.js — заявки идут только в Яндекс Форму.
- Не менять язык интерфейса: весь контент на русском.
- Не подключать внешние CDN для изображений и шрифтов, кроме уже используемых
  Google Fonts и написанного вручную кода Яндекс Формы.
- Сохранять вёрстку без горизонтального переполнения на 320–1440 px.
- Сохранять поддержку `prefers-reduced-motion`.
- Не удалять предоставленные заказчиком изображения в корне проекта
  (`*.jpg`, `*.png`, `i.webp`) и референсы в `reference_html/` — это исходники
  и материалы заказчика.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, текст, секции, SVG-спрайт, `<dialog>` формы, `<template>` с кодом встраивания |
| `assets/css/styles.css` | Все стили, адаптив, анимации; блок формы — `/* order form modal */` |
| `assets/js/content.js` | Редактируемые данные: `updated`, `taps[]`, `stage` (демо-значения) |
| `assets/js/app.js` | Reveal-анимации, параллакс, шапка, мобильное меню, рендер кранов, логика формы |
| `assets/img/` | Локальные фото и их уменьшенные `srcset`-версии |
| `assets/favicon.svg` | Иконка сайта |
| `reference_html/` | Исходные референсы дизайна — только для чтения |

Секции в `index.html`: `#top` (hero), тикер, `#now` (краны и сцена), `#pains`,
`#solution`, CTA-полоса, `#offer`, `#book` (финал), подвал.

## Как запустить

Просто открыть `index.html` в браузере. Для полноценной проверки встроенной формы
(iframe) поднять локальный сервер, например `npx serve .` или
`python -m http.server`, и открыть `http://localhost:3000` / `http://localhost:8000`.

Причина: при `file://` у страницы «нулевой» origin, и Яндекс Формы запрещают
встраивание в iframe через `frame-ancestors`. В этом случае `app.js` открывает
форму отдельным popup-окном по центру поверх страницы. Логика — в `openFormPopup()`.

## Ключевые соглашения

### CTA и форма

- Все кнопки бронирования помечены `data-cta="..."`; обработчик один на все
  (`$$('[data-cta]')` в `app.js`). Не вешать отдельные обработчики на конкретные кнопки.
- `href="XXXXXXXX"` у кнопок — только no-JS fallback. При включённом JS клик
  перехватывается через `preventDefault()`.
- Код встраивания Яндекс Формы хранится **целиком** в `<template id="yaFormTemplate">`
  (`script` + `iframe`) и вставляется в `#orderFormBody` только при первом открытии.
  Не переносить его в `<head>` и не грузить на старте — это ухудшает PageSpeed.
- При клонировании `<template>` внешний скрипт нужно пересоздать через
  `document.createElement('script')`, иначе браузер его не выполнит.
- Адрес формы: `https://forms.yandex.ru/u/6afb127cb9e5ca882335b0e7/`.
- Стили: iframe должен оставаться `width: 100% !important` и `min-height: 480px`
  (embed.js сам проставляет inline `height`, но до этого кадр может схлопнуться).
- Закрытие: кнопка `[data-close-modal]`, клавиша `Esc` (нативно для `<dialog>`),
  снятие `body.modal-open` в событии `close`.
- В шапке окна есть ссылка «Открыть в новой вкладке» как запасной путь.

### Соцссылки

- Иконка ВК — `<symbol id="i-vk">` в SVG-сприте.
- Все social-ссылки — буквальный плейсхолдер `href="XXXXXXXX"` (без `vk.com`, `t.me`).
  Не «исправлять» на реальный URL без запроса пользователя.
- Видимый текст плейсхолдера тоже `XXXXXXXX`.

### Контент

- Краны и анонс сцены задаются в `content.js` как `window.PIVBAR_DATA`.
- `app.js` ожидает массив `taps` (до 6 карточек) и объект `stage` с полями
  `day`, `time`, `title`, `text`, `tags`. Изменять структуру нужно синхронно в обоих файлах.
- Значения `color` проходят через `safeColor()` (только hex) — не используйте
  произвольные CSS-значения.
- Текст экранируется через `escapeHtml()` — сохранить это при добавлении полей.

### Стили и адаптив

- Точки переключения сеток: 1 колонка на мобильных, 3 колонки на десктопе
  (`.tap-grid`, `.pain-grid`, `.solution-grid`).
- Проверять отсутствие горизонтальной прокрутки на 320/390/820/1440 px.
- Новые интерактивные элементы делать не мельче 44×44 px.
- Анимации обязаны уважать `prefers-reduced-motion` и `noscript`-фолбэки.

## Проверка изменений

Минимальный чек после правок:

1. Открыть страницу на 390 и 1440 px, убедиться в отсутствии `scrollWidth > innerWidth`.
2. Нажать каждую кнопку `[data-cta]` — форма открывается (iframe или popup).
3. Закрыть форму кнопкой и `Esc`; проверить, что прокрутка страницы разблокирована.
4. Проверить консоль браузера на ошибки.
5. При наличии Playwright — прогнать `pw/audit.js` и `pw/test-modal.js` из временной
   папки (`C:/Users/MSI/AppData/Local/Temp/opencode/pw/`).

Ориентиры последних замеров: Lighthouse Accessibility / Best Practices / SEO — 100,
Performance ~68–70 в headless-окружении (зависит от машины).
